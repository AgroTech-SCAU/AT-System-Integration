# 桌面工作台

## 向导模式

教学使用独立的全屏交互工作区，大屏幕中操作区与指导面板分开显示，小窗口则上下分区

教学使用独立的临时后台和 Mock 适配器，不修改正式机器人工程，也不控制真实设备

操作成功后自动进入下一步，也可使用「上一步」「跳过此步」或「退出教学」

退出时安全关闭教学后台，原有工作区保留机器人、页面及未保存编辑状态

桌面工作台基于 Electron 和 React，本地运行核心负责配置管理、能力注册、任务调度及安全停止

## 入口

```bash
./install.sh
./launch.sh
```

默认不自动启动真实设备或任务，关闭桌面窗口会触发本地运行核心的安全停止流程

## 使用

- 机器人工作台用于新建、导入、选择、关闭与删除工程
- 系统搭建用于添加已有接入描述、登记功能后端及管理能力映射
- 任务编排提供层级状态机、通用行为树画布、结构列表、任务参数及输入输出绑定
- 运行调试提供系统启动、任务预检、运行状态、阻塞原因及停止入口

接入描述只提供能力声明，真实执行需已有相应适配器并通过授权，不会因为导入 YAML 自动执行未知代码

需要检查协议或手工覆盖配置的开发者可在相应页面展开高级选项

## 工程迁移

工作台支持通过 `.agrobot.json` 文件导入导出配置、状态机结构、任务和受支持的资产

工程文件不包含运行凭据、设备授权或实际驱动部署，迁移后需检查当前环境是否具备对应能力

## 安全

运行中的任务使用固定的任务定义与配置快照，编辑草稿不会改变正在执行的指令

任务取消不等于设备已经停止，系统仅在收到后端停止确认后释放安全门控


工程导入后已发布行为树的身份不会直接复用，状态机的 Entry、Do、Exit 必须重新关联当前机器人发布的任务
