# GUI 工作区验收

## 开始使用

1. 运行 `./install.sh` 和 `./launch.sh`
2. 初次进入「总览」，没有默认机器人系统；用户必须选择「新建系统」「导入系统」或「选择已有系统」
3. 新建时可以选「空白系统」或「从示例创建」；番茄案例只是一种可选示例，不在其他系统里自动出现
4. 选择示例后，在「系统搭建」查看四个后端和绑定，在「任务编排」查看当前系统的专属模板或自行新建查询树
5. 在「运行调试」启动模拟模块，检查 READY、执行预检和任务，最后停止；「记录与报告」用于核对输出
6. 桌面端默认自动认证，首页不展示手动连接表单；连接失败可在总览点「重新连接」，浏览器调试认证位于高级设置

## 工程迁移验收

1. 创建番茄采摘示例并选择系统，保存任务方案与行为树草稿
2. 在「选择已有系统」点击「导出」，保存 `.agrobot.json` 工程文件
3. 在另一全新状态目录启动同一应用，选择「导入系统」，该操作不得自动激活或启动设备
4. 导入之后在「选择已有系统」选择它，核验四后端配置及草稿、任务参数和模拟标定资产
5. 导入的发布定义只作为草稿，必须重新静态校验与发布；不直接搬迁运行授权
6. 重复导入应生成不同机器人系统 ID；篡改接入包描述、资产摘要或工程格式须被拒绝

## 删除系统验收

1. 创建两个空白系统，删除未选中的系统，确认其他系统不受影响
2. 删除当前选中的空白系统，确认列表更新且清空选择
3. 从番茄示例创建系统，激活后应禁止直接删除当前使用中的系统
4. 切换到另一个空白系统后删除原示例，确认关联草稿与任务方案被清理，运行记录仍保留
5. 模块运行中或停止状态未确认时不得删除系统

## 安全边界

- 机器人实例持久化到本机工作区；创建项目不会自动启动设备
- 系统切换只允许处于 `STOPPED` 且任务/操作停止已确认的条件下进行；切换成功后变更当前系统上下文
- 空白系统可先创建，再到「系统搭建」选择接入包、添加后端和角色；配置静态校验通过且停机后才能应用
- 同一个示例可以创建多个独立系统实例，拥有不同系统 ID，切换时重新应用配置
- 配置草稿、任务草稿和当前运行快照保持分离；行为树画布移动位置不会改变执行顺序
- 四后端共享 MockWorld，但不提供物理运动、碰撞和传感器真实性

## 验收检查

在全新工作区中检查空白启动、创建与切换系统、四后端模拟启动停止、配置草稿应用及工程导入导出

退出时确认机器人模块停止、终端返回提示符且服务端口已释放

## GUI 动画

参考 `Kaede-Rei/SerialArm-Core` 的 spring 曲线：页面先 90ms 退出，再使用回弹进入；卡片、导航、按钮与等待弹窗使用不同幅度 overshoot；遵守 `prefers-reduced-motion`，避免减少动态效果模式仍然持续动画
