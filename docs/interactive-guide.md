# 交互式教学与使用手册

本手册对应桌面 GUI 右上角的「向导」按钮

教学会聚焦实际控件并说明为什么要做这一步、应该点击哪里、操作成功后会出现什么

## 一 开始学习

1. 执行 `./launch.sh` 打开桌面 GUI
2. 第一次创建机器人时会出现「开始使用教学」邀请弹窗，可以选择开始或暂不需要
3. 勾选「不再自动提示教学」后，以后新建系统不再自动弹窗
4. 需要重新学习时点击右上角「向导」选择课程，或者在「设置 → 使用向导」重新开启创建后的邀请
5. 高亮框内的按钮可直接点击，其他区域会被遮罩覆盖
6. 带实际操作的步骤会在操作成功后自动前进，介绍步骤由用户点击「下一步」
7. 想先看后续内容时可点击「暂时跳过」，需要退出时点击「退出教学」或按 `Esc`

课程不会代替用户启动设备、接管手动控制或绕过预检

## 二 通用机器人系统教学

适合从零搭建自己的机器人，还没有设备驱动的用户也能完成基础认识

| 阶段 | 找到的位置 | 实际学习内容 | 完成标志 |
| --- | --- | --- | --- |
| 创建系统 | 总览 → 空白机器人 | 输入系统名称并创建 | 总览显示新系统 |
| 进入搭建 | 左侧 → 系统搭建 | 认识视觉、导航、机械臂、电控 | 进入搭建页面 |
| 建立草稿 | 保存系统配置 → 开始配置 | 学习草稿与生效配置的区别 | 出现参数和后端编辑项 |
| 认识实例 | 机器人参数与能力绑定 | 区分系统标识、实例标识和接入包 | 理解一个服务对应一个实例 |
| 接入包 | 高级：接入包管理与配置历史 | 查找或导入 `package.yaml` | 能看到接入包目录 |
| 后端配置 | 新实例标识和接入包 | 选择可用接入包并将实例加入草稿 | 后端列表增加实例 |
| 能力绑定 | 高级：完整角色绑定与参数 | 认识任务能力与具体实例的对应关系 | 了解兼容性限制 |
| 保存校验 | 保存并检查配置 | 查找缺少的依赖和不合法端口 | 显示校验结果 |
| 应用配置 | 应用到系统 | 确认系统停止后应用已验证配置 | 当前配置更新 |

### 空白系统为什么不能马上运行

空白系统没有自动安装相机驱动、机械臂控制器、底盘驱动或任务模板

要真正调用后端，必须提供相应接入包描述和符合接口契约的运行实现

如果目前没有接入包，学习完基础概念即可结束课程，不能为了让界面出现「就绪」而填入虚假配置

## 三 番茄采摘示例教学

适合第一次理解完整的系统集成流程，推荐先学这一套，再返回空白系统搭建自己的机器人

### 1 创建练习系统

1. 总览 → 新建系统 → 从示例创建
2. 修改或保留推荐系统名称
3. 点击「创建并选择」
4. 等待系统加载后进入「系统搭建」

### 2 看懂四个模拟后端

| 功能系统 | 示例职责 | 运行中要关注什么 |
| --- | --- | --- |
| 视觉 | 检测候选番茄并提供目标信息 | 目标信息是否可用 |
| 导航 | 到达作业位置 | 移动动作的成功与失败 |
| 机械臂 | 计算与执行采摘运动 | 动作执行及反馈 |
| 电控 | 控制末端与其他设备 | 夹持、释放及工具状态 |

四后端共享模拟世界状态，初始未就绪不代表配置不存在

注意这里验证的是后端能力调度，不包含物理碰撞或动力学仿真

### 3 保存任务方案

1. 点击「任务编排」并留在「任务模板」
2. 查看可编辑参数和只读任务限制
3. 「绑定标定资产」先保留内置模拟标定
4. 点击「保存为新任务方案」
5. 确认方案出现在下拉框中
6. 可以点击「预检方案」了解当前缺少的运行条件

任务方案只是一次任务的参数记录，保存并不会启动机器人

### 4 阅读行为树

1. 点击「行为树编辑」
2. 点击「从当前系统示例创建」
3. 等待草稿出现后查看「节点库」
4. 从画布根节点开始认识节点连接与任务流程
5. 选择画布中的节点，阅读节点设置里的能力角色和端口
6. 找到「保存草稿」「校验树」「发布定义」三个操作

画布拖动只改变显示布局，执行顺序需要使用节点设置中的「上移」「下移」

草稿不等于可以执行的定义，发布前需要检查节点模型和端口契约

### 5 运行调试

1. 点击左侧「运行调试」
2. 认识「启动系统」「停止系统」和「接管手动控制」
3. 查看「就绪检查」中的进程、接口、数据、授权
4. 在「已保存方案」里选择刚才创建的方案
5. 通过「检查方案」核对条件，所有必要条件满足后才考虑执行
6. 通过「任务观察」查看已有任务与停止确认

教学只介绍运行操作，不会自动点击启动系统或开始任务

若执行器不可用，请先检查 `./install.sh` 对 BehaviorTree.CPP 的构建结果，不能将无法执行的任务视为已完成验证

## 四 常见问题

| 现象 | 建议检查 |
| --- | --- |
| 高亮区域不存在 | 等待页面加载，必要时点击「前往本步所在页面」，确认对应面板没有被隐藏 |
| 某个按钮是灰色 | 检查前置配置、是否选择方案以及安全和系统运行状态 |
| 创建配置后没有看到真实设备 | 创建草稿不会安装硬件驱动，也不会启动设备 |
| 空白系统没有番茄任务 | 这是正常行为，番茄模板仅随示例机器人创建 |
| 保存任务方案后不能启动 | 先检查模块状态、任务预检、运行授权和行为树执行器 |
| 后端显示已绑定但未就绪 | 检查后端进程、接口、数据与授权，不要混淆配置和运行状态 |
| 想重新开始课程 | 右上角「向导」重新选择即可，不会自动删除当前系统 |
| 不想再弹出邀请 | 勾选「不再自动提示教学」，或在设置中关闭创建后邀请 |

## 五 开发维护

- 课程内容位于 `gui/src/guide/courses.ts`
- 遮罩定位、卡片布局与交互位于 `gui/src/guide/GuideOverlay.tsx` 和 `gui/src/guide/guide.css`
- 新建系统后的邀请与课程状态位于 `gui/src/App.tsx`
- 页面上需要有稳定的 `data-guide` 目标标识
- 实际操作型步骤要在服务端确认成功后发送 `guideCompleted('事件名')`
- 修改课程后检查教学目标标识、步骤事件和中英文文案是否与页面一致

不要在教程里直接修改机器人运行状态，也不要通过跳过步骤来绕过安全检查
