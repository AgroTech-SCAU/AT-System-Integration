# 真实 GUI 隔离教学

## 核心原则

- 教学复用正式工作台的总览、系统搭建、HSM、BT、运行和记录页面，不维护另一套简化的业务编辑界面
- 正式工作台在教学过程中保持挂载，原有页面和未保存编辑状态不会因教程切换而卸载
- 教学 API 使用独立临时状态目录与模拟适配器，不能启用真实驱动或系统服务
- 全屏模糊遮罩作用于教学工作台，只在当前真实操作控件周围留出可点击区域，指导面板不遮挡操作区
- 教学结束销毁模拟运行上下文，回到进入前的正式 GUI

## 使用流程

1. 在任意正式工作区的右上角打开向导
2. 选择通用机器人或番茄采摘示例课程
3. 软件启动独立的临时 Mock 后台，在同一套 GUI 中显示教学工作区
4. 按右侧提示操作高亮的真实按钮、输入框和树编辑器
5. 创建练习机器人后，继续通过正式系统搭建、HSM、BT 和运行页面操作
6. 完成教学或随时点击退出，等待模拟运行安全关闭后返回正式工作台

## 教学与正式运行的区别

| 项目 | 正式工作台 | 隔离教学工作台 |
| --- | --- | --- |
| GUI 组件 | 正式组件 | 相同的正式组件 |
| 系统配置 | 当前机器人数据 | 临时练习数据 |
| 状态机和行为树 | 正式保存与执行接口 | 相同接口的独立模拟实例 |
| 适配器 | 可按项目部署 | 仅允许内置 Mock |
| 进程管理 | 实际进程与服务 | 不启动操作系统进程的模拟管理器 |
| 结束后 | 数据按正常规则保存 | 临时数据销毁 |

## 操作注意

- 用户完成当前指引的实际操作后，界面收到成功结果便自动进入下一步，不需要额外点击确认
- 「跳过此步」仅跳过当前操作提示，不自动保存配置、创建任务或执行设备操作，后续步骤如依赖该操作仍需补齐
- 「上一步」可重新查看前一步骤，「退出教学」结束隔离练习并返回正式工作区
- 选择类别和节点等交互直接触发切换，保存、发布、配置应用和运行操作必须等待结果确认
- 操作失败时保留当前步骤与诊断信息，不会将点击按钮当成操作成功
- 当前步骤要求保存机器人、状态机或任务时，需要通过真实 GUI 成功完成对应操作
- 没有已应用的模拟后端时，运行工作区仍会阻止启动，此时需要先在系统搭建中完成配置
- 如果 BehaviorTree.CPP 执行器不可用，教学中的发布和执行也会如实显示缺失条件
- 关闭教学不是关闭正式机器人，不会发送控制命令到正式工作台
