# AT-System-Integration

面向机器人开发者的系统集成工作台，用统一的 GUI 管理机器人功能后端、行为树任务与运行状态可从空白机器人搭建系统，也可导入示例或已有工程

本项目以 **GUI + 本地运行核心 + 能力适配器 + BehaviorTree.CPP 执行器** 为基础GUI 面向配置和任务编排，运行核心负责配置校验、能力调度、权限门控、任务执行与停止确认桌面模式无需手动连接管理服务

## 功能

| 工作区 | 用途 |
| --- | --- |
| 总览 | 新建、导入、选择、导出与删除机器人系统；查看已选系统状态 |
| 系统搭建 | 配置视觉、导航、机械臂、电控等后端及能力绑定，保存并应用配置 |
| 任务编排 | 使用任务模板、编辑行为树、设置参数与端口映射、校验任务 |
| 运行调试 | 检查能力就绪情况，启动/停止系统，执行、取消并观察任务 |
| 记录报告 | 查询任务历史和运行记录 |

- **工程文件**：可导入、导出 `.agrobot.json`，用于迁移系统配置和受支持的任务、资产；不包含会话密钥和真机运行授权
- **交互式教学**：新建后可选择开始；右上角「向导」随时进入，分别提供通用系统搭建和番茄采摘示例课程
- **独立系统**：一个工作区可保存多个机器人系统，创建示例不会改变其他系统的配置
- **安全控制**：配置应用需满足停止态约束；编辑草稿不会替换运行中任务；停止未确认时保留安全处理入口

## 环境与安装

主要面向 **Ubuntu Linux 桌面**需要 Python 3.10+、Node.js 22.12+（或受支持的 24+）、npm、CMake、C++17 编译器、`pkg-config`、libcurl 开发包，以及 Electron 所需的图形桌面运行库

首次安装

```bash
./install.sh
```

直接打开

```bash
./launch.sh
```

默认将 Python 虚拟环境、前端构建、Electron 和行为树执行器放到仓库内 `.install/`首次构建 BehaviorTree.CPP 可能需要下载依赖；已下载源码时可使用

```bash
./install.sh --bt-source /path/to/BehaviorTree.CPP
```

`./launch.sh` 在当前终端前台运行关闭桌面主窗口或按 `Ctrl+C` 时，会请求安全停止运行核心和已启动模块；如真实设备停止尚未确认，不会强制结束控制进程默认打开 GUI 不启动机器人设备或任务

## 快速开始

### 1. 从空白系统开始

1. 打开「总览」，选择「空白机器人」，输入机器人系统名称，点击「创建并选择」
2. 如果希望有人机交互提示，选择「开始教学」；不需要则跳过
3. 进入「系统搭建」→「开始配置」，添加接入包与后端实例，设置能力绑定
4. 保存并检查配置，在系统停止时应用配置
5. 完成任务定义后，在「任务编排」中校验行为树，再到「运行调试」进行预检与执行

空白系统不会自动拥有后端或任务模板新增硬件系统时需要提供对应的接入包描述与可用实现

### 2. 使用番茄采摘示例

1. 在「总览」选择「从示例创建」→「番茄采摘机器人」，输入名称并创建
2. 可启动番茄实践教学，了解四类功能后端、采摘任务模板和行为树结构
3. 在「系统搭建」查看 `vision`、`navigation`、`arm`、`control` 四个模拟后端
4. 在「任务编排」保存任务方案，检查行为树结构和参数
5. 在「运行调试」核对就绪状态后，再尝试启动模拟系统与任务

示例文件位于 [`examples/tomato_picker/`](examples/tomato_picker/)四后端共享模拟世界状态，但这是**能力层模拟（Mock）**，不是 Gazebo / Isaac Sim 物理仿真完整任务执行需要可用的 C++ 行为树执行器，且必须通过任务预检

### 3. 导入、导出工程

在「总览」使用「导入系统」选择 `.agrobot.json`，或从「选择已有系统」中导出当前工程导入系统会创建新的系统身份；选择后需要检查接入包、配置、任务草稿与标定资产，**不会因导入而直接控制设备**

### 4. 删除已有系统

在「总览 → 选择已有系统」中找到目标系统，点击「删除」，输入系统名称并确认

删除前必须停止所有任务与设备，正在使用的系统需要先切换到其他机器人系统

删除会清理该系统的配置、未发布任务草稿和任务方案，保留运行记录及已发布任务定义以便追溯

## 新手教学

**推荐第一次使用先完成番茄采摘示例教学，再从空白系统搭建自己的机器人**

- 创建空白系统或番茄示例成功后，可以选择「开始教学」或「暂不需要」
- 勾选「不再自动提示教学」后，不影响日后从右上角「向导」重新学习
- 右上角「向导」随时提供「通用机器人系统」和「番茄采摘示例」两套课程
- 教学会框住真实按钮并在旁边说明用途、操作方法、预期结果和常见问题
- 创建系统、创建配置草稿、保存任务方案等步骤在操作成功后自动继续
- 阅读型步骤可以点击「下一步」，遇到缺少驱动或执行器时可以「暂时跳过」
- 整个教学不会替你启动真实设备或跳过安全预检

详细操作和问题排查见 [`docs/interactive-guide.md`](docs/interactive-guide.md)

### 建议学习顺序

| 学习阶段 | 你会学到什么 | 实际动手操作 |
| --- | --- | --- |
| 认识工作区 | 系统搭建、任务编排和运行调试的关系 | 新建一个练习系统 |
| 认识后端 | 视觉、导航、机械臂、电控如何接入 | 查看四类模拟后端 |
| 配置与校验 | 接入包、实例、能力角色、草稿与应用 | 创建并保存配置草稿 |
| 任务方案 | 任务参数和模拟标定资产 | 保存一个任务方案 |
| 行为树 | 控制节点、动作节点与输入输出端口 | 创建示例树草稿并阅读结构 |
| 运行检查 | 模块就绪、预检、停止确认 | 查看诊断和任务观察 |

## 架构

```text
Electron / React GUI
        │  本机管理接口
        ▼
运行核心（Agent / API / 校验与安全门控）
        ├── 接入包与能力注册表
        ├── 配置草稿、快照、系统工程
        ├── 行为树任务执行器（BehaviorTree.CPP）
        └── 后端适配器
             ├── 视觉   ├── 导航
             ├── 机械臂 └── 电控
```

桌面自动连接本机运行核心；本地 HTTP API 是 GUI 与运行核心之间的通信方式，不要求通过浏览器使用架构与后端契约见 [`docs/architecture.md`](docs/architecture.md) 和 [`contracts/`](contracts/)

## 工程目录

```text
adapters/          后端适配器与模拟实现
contracts/         系统、能力与运行相关的数据契约
docs/              架构、计划、验收及教学说明
examples/          空白工作区及番茄采摘示例
gui/               Electron 桌面入口与 React 工作台
src/               运行核心与管理接口
task_engine/       BehaviorTree.CPP 执行器
install.sh         安装脚本
launch.sh          前台启动脚本
```

## 验证与排查

修改 GUI 后可检查

```bash
npm --prefix gui ci
npm --prefix gui run typecheck
npm --prefix gui run build
```

开发端口由启动器管理；如遇端口占用，先检查旧进程与任务停止状态，避免直接对仍在控制机器人的进程执行 `kill -9`
